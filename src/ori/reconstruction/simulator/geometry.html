Direct FOLD files display the geometry supplied in each frame. Older action plans use derived point folds or the labeled square-base template. Selecting a state does not imply a physically valid motion between states.

Crease patterns use the GPU solver. Folded 3D states are displayed directly, with simulation disabled. Layer ordering is preserved in the file but not enforced by the renderer.
